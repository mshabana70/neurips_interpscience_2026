## Per-example audit data

The public label files preserve trial-level auditability without publishing generated text:

```text
results/public_labels/arditi_gap/<model>.json.gz
results/public_labels/h3_causal/<model>.json.gz
results/public_labels/paper_closure/<model>.json.gz
```

Each row retains the experiment arm, record identifier, attack class where applicable, judge outcome, incoherence flag, and token-cap metadata available in the raw run. `scripts/export_public_labels.py` implements the deterministic redaction.

## Reproduction boundaries

The CPU figure build is complete from the checked-in aggregate artifacts. A fresh end-to-end behavioral reproduction requires model weights and a judge API because raw generations are not distributed. It must run H2 before F1, H3, and closure; the compact public H2 label file intentionally cannot substitute for the local full-text `judged.json` consumed by those stages.
